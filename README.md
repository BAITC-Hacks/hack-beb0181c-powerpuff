#  EKT AI Assistant — Powerpuff

ИИ-ассистент для сайта **ekt.kz**, который помогает клиентам быстро находить электротехнические товары, проверять наличие, получать характеристики, подбирать аналоги и переходить к покупке.

Проект команды **Powerpuff** для **HackAlem AI Hackathon**.

---

##  Цель проекта

Упростить поиск и выбор товаров на **ekt.kz** и сократить количество типовых обращений к менеджерам.

Вместо ручного поиска по большому каталогу пользователь может написать обычный запрос:

> «Нужен автомат Legrand на 160А»

ИИ-ассистент понимает запрос, находит подходящие товары и показывает актуальную информацию из каталога.

---

##  Почему AI

Обычный поиск удобен, когда пользователь уже знает точное название или артикул товара.

ИИ-ассистент позволяет искать товары **естественным языком** и объединяет в одном окне:

-  поиск товара;
-  проверку наличия;
-  характеристики и сертификаты;
-  подбор аналогов;
-  информацию об условиях покупки;
-  добавление товара в корзину после подтверждения пользователя.

> **AI отвечает за понимание запроса, а цена, наличие и характеристики берутся из данных каталога.**

---

##  Что реализовано

-  AI-чат для работы с каталогом
-  Поиск товаров
-  Получение информации и характеристик товара
-  Проверка общего наличия
-  Проверка остатков по складам
-  Подбор аналогов
-  Переход на страницу товара
-  Работа с корзиной после подтверждения пользователя
-  Интеграция Frontend → Backend → AI/ML

---

##  Как работает решение

```text
Пользователь
     ↓
React Frontend
     ↓
Spring Boot Backend
     ├──→ EKT API / данные каталога
     ↓
AI / ML Service
     ↓
Ответ и карточки товаров
```

### Пользовательский сценарий

1. Пользователь открывает AI-ассистента.
2. Пишет запрос обычным языком.
3. AI определяет намерение и параметры поиска.
4. Backend получает необходимые данные.
5. Frontend показывает найденные товары.
6. Пользователь может посмотреть характеристики, наличие и аналоги.
7. После явного подтверждения выбранный товар можно добавить в корзину.

##  Запуск

### Требования

- Java 21
- Maven
- Node.js 20+
- Python 3.11+

Схема локального запуска:

```text
frontend :5173 → backend :8080 → ml :8000
```

### 1. Backend

```bash
cd backend
mvn spring-boot:run
```

Проверка:

```text
http://localhost:8080/api/health
```

Ожидаемый ответ:

```json
{
  "status": "ok"
}
```

По умолчанию используется **H2 in-memory**, поэтому отдельную базу данных устанавливать не требуется.

H2 Console:

```text
http://localhost:8080/h2-console
```

JDBC URL:

```text
jdbc:h2:mem:hackdb
```

User:

```text
sa
```

### PostgreSQL

```bash
docker compose up -d

cd backend

SPRING_PROFILES_ACTIVE=postgres mvn spring-boot:run
```

---

### 2. ML-сервис

```bash
cd ml

python3 -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

python -m src.train

uvicorn app.main:app --reload --port 8000
```

Подробнее:

```text
ml/README.md
```

---

### 3. Frontend

```bash
cd frontend

npm install

npm run dev
```

Открыть:

```text
http://localhost:5173
```

Запросы на `/api` проксируются на backend:

```text
http://localhost:8080
```

##  Данные и интеграции

Ассистент работает с данными каталога EKT.

- ID;

Пример потока данных:

```text
EKT Catalog / API
        ↓
Spring Boot Backend
        ↓
AI Assistant
        ↓
React Frontend
        ↓
Пользователь
```

---

##  Основные ограничения

Ассистент не должен:

- изменять корзину без явного подтверждения пользователя;
- оформлять заказ без подтверждения;
- придумывать цену или наличие товара;
- запрашивать или хранить платёжные данные клиента.

При работе с товарами используются доступные данные каталога.

---

##  Ценность решения

**Для клиента:**

- быстрее найти нужный товар;
- получить характеристики в одном месте;
- проверить наличие;
- найти замену отсутствующему товару;
- сократить путь от поиска до покупки.

**Для EKT:**

- автоматизация типовых консультаций;
- снижение нагрузки на менеджеров;
- более удобная работа с большим каталогом;
- помощь клиенту при выборе и поиске аналогов.
